Overview · Built-in Dye-Sub Engine

How 4×6 Whole and 2×6 Split Work on HiTi

Commercial HiTi roll printers load a single 4×6 media roll and print both formats automatically — the printer's internal blade cuts 2×6 strips down the center on the final pass.

4R (4×6) Whole Sheet

Sent to Printer 1 (HiTi 4x6). Prints edge-to-edge at 300 DPI (1200×1800 px), uncut.

2×6 Split Strips (2 copies per sheet)

Sent to 2×6 Split Printer (HiTi 2x6 cut). Two identical strips side-by-side sliced down the center seam.

Hardware Check: Which HiTi Models Auto-Cut 2×6?

Auto-cut supported (built-in cutter): HiTi P525L, P520L, P510S, P510L, P510K, P720L, P750L (must have 4×6 media loaded).
No built-in cutter (compact sheet models): HiTi P310W, P322W, S420 — photobooth4u still prints two 2×6 strips side-by-side on a 4×6 sheet, ready for a manual paper trimmer.

Choose Your Setup Mode

Dual-Queue (LumaBooth-Style) vs. Single-Queue Auto-Split

photobooth4u supports both methods out of the box. Pick Dual-Queue for maximum stability across every HiTi model and driver version.

Option A · Dual-Queue Recommended

Install the same HiTi twice on the same USB port: HiTi 4x6 and HiTi 2x6 cut (same workflow as LumaBooth's Primary + Secondary Printer).

  • 100% reliable across all HiTi models & driver versions — even drivers where 2-inch cut is a checkbox instead of a paper size.
  • Independent settings per mode: separate Lightness, Colour Balance, Edges, and Glossy/Matte overcoat for 4×6 vs 2×6.
  • photobooth4u preserves each queue's private HiTi driver settings automatically.

Option B · Single-Queue Auto-Split Fast Setup

Keep just one printer queue (e.g. HiTi P525L). Works whenever your HiTi driver lists both 6x4 and 6x4 Split (6x2 2 prints) / 6x4/2-UP as paper sizes.

  • No duplicate printer queue needed.
  • photobooth4u automatically switches to 6x4 Split / 2-UP for strip layouts and switches back to whole 6x4 for 4R layouts.
  • If your driver uses a custom split name, you can lock the exact slot once under 2×6 split driver paper slot.

Steps 1 & 2 · One-Time Setup on Your Laptop

Install HiTi Driver & Create the 2×6 Cut Queue

Always install the official HiTi driver from HiTi's support website — never use macOS AirPrint or Windows Generic drivers.

Windows (10 / 11)

  1. Install the HiTi Windows driver for your model, load 4×6 ribbon & paper, and plug in via USB.
  2. Open Control Panel → Devices and Printers (or Settings → Printers & scanners). Open your HiTi → Printing preferences → select 6×4 (whole, uncut), borderless → OK. Rename it HiTi 4x6 under Printer properties.
  3. For Option A (Dual-Queue): in Control Panel → Devices and Printers, click Add a printer → The printer that I want isn't listed → Add a local printer… with manual settings.
  4. Pick Use an existing port → select the exact same USB port your first HiTi uses (e.g. USB001) → select your HiTi driver → Use the driver that is currently installed → name it HiTi 2x6 cut.
  5. Open HiTi 2x6 cut → Printing preferences → choose 6x4 Split (6x2 2 prints) / 6x4/2-UP (or tick the 2-inch cut option) → click Apply & OK.

macOS (Apple Silicon & Intel)

  1. Install the HiTi macOS driver for your model, restart the Mac, load 4×6 media, and connect via USB.
  2. System Settings → Printers & Scanners → Add Printer. Pick the HiTi, verify Use shows the official HiTi driver (not Generic), name it HiTi 4x6 → Add.
  3. For Option A (Dual-Queue): click Add Printer again, select the same HiTi, name it HiTi 2x6 cut → Add.
  4. Enable the CUPS settings page in Terminal, then open http://localhost:631/printers in Chrome (login with your Mac username & password):
    cupsctl WebInterface=yes
  5. Set defaults for each queue (Administration → Set Default Options):
    • HiTi 4x6 → Media Size 6x4 (uncut) → Save.
    • HiTi 2x6 cut → Media Size 6x4 Split / 6x4 (2x6 ×2) (or enable the 2-inch cut option) → Save.

Important: Keep “HiTi” in the Printer Name

Names like HiTi 4x6, HiTi 2x6 cut, or HiTi P525L tell photobooth4u to activate its dedicated dye-sub print engine — preserving your driver's private cut/finish/colour settings, preventing inkjet scaling, and rendering full-bleed edge-to-edge with crisp TileFlipXY filtering.

Step 4 · All-Device Seamless Printing

Using HiTi from an iPad or Android Tablet

HiTi printers require HiTi's Windows/macOS driver for heat & colour calibration, so tablet booths print silently through a Windows or Mac laptop plugged into the HiTi via USB.

Method 1 · Laptop App LAN Sharing Best for iPad · Offline

  1. Plug the HiTi into your laptop and open the photobooth4u Laptop App.
  2. Configure Printer 1 (HiTi 4x6) and 2×6 Split Strips Printer (HiTi 2x6 cut) on the laptop.
  3. Go to Setup → Share & start and enable iPad sharing.
  4. Open the shown local link (http://<laptop>:47777/ipad/<PIN>) on your iPad. Every 4×6 and 2×6 print goes straight to the laptop over local Wi-Fi at 300 DPI lossless PNG — no internet needed.

Method 2 · Cloud Print Station iPad & Android

  1. On the laptop plugged into the HiTi, open the Print Helper and go to photobooth4u.netlify.app/print-station/, then sign in with your booth code.
  2. Pick your printers right on the Print Station page:
    • 4R (4×6) → HiTi 4x6
    • 4R (4×6) · 2×6 strips (cut) → HiTi 2x6 cut (or leave on Same as 4×6 auto-split)
  3. Tap Test 4×6 whole and Test 2×6 strips (cut) on the laptop to verify both cuts.
  4. On your iPad or Android tablet, open Print settings → Send prints to → Send to a laptop print station. Guests can pick 4×6 or 2×6 layouts and the laptop routes each print automatically!

Under the Hood · Print Quality

What photobooth4u Automatically Protects for HiTi

True 300 DPI Native Output

Every 4×6 and 2×6 dual-strip sheet renders at exact 300 DPI (1200×1800 px) with an integer center seam (600 px + 600 px) so there is never a white gap along the cut line.

Private Driver Settings Kept Intact

On Windows, photobooth4u skips PrintTicket overrides on HiTi/dye-sub queues — so your driver's 2-inch cut, matte/glossy finish, and HiTi colour table are never reset mid-event.

Crisp Full-Bleed, Zero Hairlines

Uses high-quality bicubic resampling with TileFlipXY edge wrapping and full-bleed dye-sub framing — eliminating 1 px white borders and accidental inkjet shrinking.

Quick Fixes

Troubleshooting Checklist

ProblemSolution
Strips print side-by-side but aren't cut Open HiTi 2x6 cut → Printing preferences (Windows) or localhost:631/printers → Set Default Options (Mac) and make sure 6x4 Split (6x2 2 prints) / 2-inch cut is saved as the default. In photobooth4u, verify 2×6 Split Strips Printer is set to HiTi 2x6 cut.
Whole 4×6 photo gets cut in half Check HiTi 4x6 driver defaults — set paper to regular uncut 6×4 (not Split). In single-queue mode, check Driver paper size / slot under Printer 1 is on Auto match or 6x4.
HiTi LCD shows “Paper Mismatch” Confirm a 4×6 media roll & ribbon is loaded. 2×6 split cutting only works on 4×6 media (not 5×7 or 6×8 rolls).
White edge or slight trim along one side Make sure the printer name contains HiTi. Then tap Print edge test inside that printer's card and adjust Edges (margins) in 0.5 mm steps (+ pulls image inward, − pushes outward).
Print looks slightly dark or warm Open Lightness & Colour Correction inside that printer's card (independent per printer!) and raise Lightness by +10 to +25. Guests' digital/QR copies stay untouched.
HiTi not showing in the app's printer list Check the HiTi is powered on and USB cable is secure, confirm it appears in Windows/Mac Printers & Scanners, then tap Refresh printer list (or restart Print Helper).
