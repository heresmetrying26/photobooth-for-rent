MacBook + Epson L8050

Install the printer on your MacBook, then connect it to the photobooth4u app

MacBook (macOS 11 or newer)Epson L8050photobooth4u Mac app

1Before you start

  • The photobooth4u Mac app is installed. Get it at photobooth4u.netlify.app/downloads. Choose Apple Silicon (M1, M2, M3...) or Intel. Not sure? Apple menu → About This Mac.
  • First time opening the app: right-click it → Open. If the Mac still blocks it: System Settings → Privacy & Security → Open Anyway. If the Mac asks about network connections, click Allow.
  • The printer is switched on, all ink tanks are filled, and 4x6 (4R) glossy photo paper is in the rear tray, glossy side up.
  • A USB cable for the printer. A MacBook with only USB-C ports needs a USB-C to USB-B cable (or an adapter).

2Connect the printer to the MacBook

Option A: USB cable Best for events

Plug the cable into the printer and the MacBook, then switch the printer on. Works anywhere, with or without Wi-Fi.

Option B: Wi-Fi

Join the printer to the same Wi-Fi as the MacBook (use the printer's own Wi-Fi setup, or the Epson Smart Panel app on your phone). Avoid venue “guest” Wi-Fi: it often stops devices from seeing each other.

3Install Epson's driver, then add the printer

  1. Apple menu → System Settings → Printers & Scanners. (macOS 11 and 12: System Preferences → Printers & Scanners.)
  2. Is EPSON L8050 Series already listed? Click it, then Options & Supplies. If you see both an Options tab and a Utility tab, it already uses Epson's driver: go to step 6. If not, select it and click the − button (Remove Printer).
  3. Install Epson's driver first. Open the Epson L8050 page on your country's Epson Support website and click the Downloads tab. In the Operating System menu, pick your Mac version (Apple menu → About This Mac shows it, for example Mac OS 15.x). Download the printer driver, open it and follow the installer.
  4. Back in Printers & Scanners, click + (Add Printer, Scanner, or Fax). Pick EPSON L8050 Series: the USB one for a cable, or the Bonjour / Wi-Fi one for Wi-Fi.
  5. Look at the Use box. It must say EPSON L8050 Series, not AirPrint, Secure AirPrint or Generic PostScript. Click Add. No Epson choice in Use? The driver from step 3 did not install: run it again, then repeat step 4.
  6. Check it: select the printer → Options & Supplies → Utility → Print Test Page. Paper comes out? The driver works.
Keep “L8050” in the printer's name. The app uses it to apply the settings made for this printer (borderless 4x6). Don't rename it to something like “Photo printer”. If you ended up with two L8050 entries (one USB, one Wi-Fi), remove one.

4Connect it to the photobooth4u app

  1. Open the app → Setup → Print settings. Under Paper size, pick the size you print (for example 4x6). The Printer 1 card below is the printer for that size.
  2. Open the Printer 1 list and pick EPSON L8050 Series. Not there? Tap Refresh printer list. Still not there? Check the cable or Wi-Fi, and that it shows in Printers & Scanners.
  3. Wi-Fi shortcut: Find a Wi-Fi, Bluetooth, or Instax printer → Find Wi-Fi / network printers. Your L8050 should say on this computer as “EPSON L8050 Series”: tap Use this printer. If it says Add to this computer instead, don't tap it. Go back to step 3 first, so the Mac gets Epson's driver.
  4. In the same card: keep Print quality on Best. Under Paper / media type, pick the glossy photo paper choice. Leave Driver paper size / slot on Auto match: it picks a borderless 4x6 when the driver has one. (Configure printer shows every Epson driver option if you need more; tap Save printer settings after a change.)
  5. Check with a real print: tap Print edge test (one test sheet on the chosen paper), or run one practice session and tap Print. Look at the photo: nothing cut off at the edges, no white line.
  6. Edges cut off or a thin white line? The edge test prints a scale on every side. Find the first bar you can see on each side. Under Edges (margins): side cut off, press +; thin white line, press −. The app already has settings for the L8050 on 4x6, so you may not need to change anything.
  7. Happy with the test? Run a few full sessions. Then switch on Send a print automatically after each session (Auto-print).

?Something not right?

  • 1Printer missing in the app: unplug and re-plug the USB cable, switch the printer off and on, tap Refresh printer list.
  • 2Wi-Fi printer vanished: the Mac and the printer must be on the same Wi-Fi. At events, use the USB cable.
  • 3Nothing prints: System Settings → Printers & Scanners → your printer → Open Print Queue. If it says paused or offline, resume it.
  • 4Dull or not glossy: Paper / media type must match the paper loaded (glossy), and Print quality must be Best (step 4).
  • 5Prints on the wrong paper size: the paper size in the app must match the paper in the tray.
