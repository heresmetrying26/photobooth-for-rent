SELPHY by Wi-Fi, and quick fixes

Use Wi-Fi only when there is a router or venue Wi-Fi.

Print over Wi-Fi instead of USB

Needs a router / venue Wi-FiBooth Wi-Fi: OFFNo cable
  1. On the SELPHY open its Wi-Fi settings and join the router (menu names differ by firmware).
  2. Join the Redmi to the same Wi-Fi.
  3. In the app: Setup → step 4 → Printer 1 → Find Wi-Fi / network printers.
  4. Tap the SELPHY in the list so it shows ✓, then tap Test print.
  5. Not listed? Type its IP in “Not listed? Type its IP” and tap Search. Last resort: pick Android print screen · any printer.
Booth Wi-Fi ON means USB. While it is on, the phone may not be able to use the router. The SELPHY’s own “Direct Connection” network is not for guests either: use USB there.

Something not working?

“Tap to allow USB access”Tap the printer name, allow, tick Always open.
SELPHY not listed (USB)Unplug and replug. Try another cable. If your Redmi has Settings → Additional settings → OTG connection, switch it on.
“Incorrect paper / Media mismatch”Paper and ink must be the same size set (e.g. 4×6 postcard).
“Ink cassette empty”The ribbon is used up. Put in a new ink cassette.
“Paper feed error”Push the paper cassette in until it clicks. Do not overfill it.
Guest photo link won’t openTheir phone left the booth Wi-Fi. Join it again, then rescan.
