Photo Booth Setup

Quick guide for your Canon, tablet and Epson printer

Canon M50 IISamsung Tab S9+Epson L5590 / L8050 / L18050

1Light

  • Set the bulb to 5500K (white / daylight) with its remote. Put batteries in (pull out the plastic tab) and point it at the bulb.
  • Press ON. Press Section to jump between the 3 presets (3200K, 4000K, 5500K) until the light looks white, not orange.
  • Fine tune: CT+ = whiter / cooler, CT- = warmer / orange. Up and down arrows = brightness.
  • Softbox slightly above eye level, angled down, 1 to 1.5 m away.
  • Guests face the light, not the window. Close the curtains if you can.
  • Use a plain white or grey backdrop, not the red wall.

2Camera

  • Mode dial on M (not video). Quality: JPEG.
  • White balance: Daylight (not Auto).
  • Camera Wi-Fi and Bluetooth off. Live View shooting on.
  • Start at ISO 400, f/4, 1/125. Adjust until a test photo looks right.
  • Full battery, SD card in, auto power off set to the longest time.

3Connect

  • Cable from the camera's Micro-USB port to the tablet's USB-C port. It must be a data cable (the old Android phone cable works). Tap OK on the USB prompt.
  • App: Setup → 3 Camera → DSLR / mirrorless over USB. Live view should show.
  • Keep the tablet on a charger.

4Printer

Option A: Booth Wi-Fi (router or venue Wi-Fi)

On the printer panel open Wi-Fi setup, pick the booth Wi-Fi and enter the password. Join the tablet to the same Wi-Fi. App: Setup → Print settings → Find Wi-Fi printers, then tap your printer. Not listed? Print the printer's network status page, type its IP address and tap Add.

Option B: Tablet hotspot (no router, no internet needed)

Tablet: Settings → Connections → Mobile Hotspot. Set the band to 2.4 GHz and turn off the auto-off timer, then switch it on. On the printer panel, Wi-Fi setup, join the tablet's hotspot. In the app tap Find Wi-Fi printers (or Add its IP address).

Option C: USB cable

Plug the printer into the tablet with a USB cable and OTG adapter. Tap OK on the prompt, then pick it in Print settings and tap Test print. If it says "no driver", use Wi-Fi.

  • Photo paper must match the paper size chosen in the app.

5Test before guests arrive

  • Do one full session and one print. Check the colour on the photo, not the live view.
  • Run 10 sessions in a row. Then switch on Auto-print.

?Photos look brown?

  • 2Camera white balance: Daylight, not Auto
  • 3Close the curtains, guests face the softbox
  • 4Plain backdrop, no red wall behind
  • 5Photo too dark? Raise ISO or open the aperture
  • 6Booth filter set to None
