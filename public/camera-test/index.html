USB camera test

Checks whether your camera can be remote-controlled from the browser: live view, real shutter (flash works), full-resolution photo. Set the camera's USB mode to Photo Import / Remote Control (Canon) or MTP/PTP (Nikon).

Before you start

    Close Photos, Image Capture, EOS Utility, Nikon apps and any other tab using the camera. Use Chrome or Edge on a Mac.

    Windows: one-time driver switch

    On Windows the camera won't appear in the list until its driver is switched to WinUSB with the free tool Zadig. While switched, Windows Photos / File Explorer / Nikon & Canon apps can't see this camera (you can switch back any time).

    1. Plug in the camera (USB mode PTP/MTP or Photo Import / Remote Control) and switch it on.
    2. Download and run Zadig: zadig.akeo.ie
    3. Options → List All Devices, pick your camera (e.g. "D5600", "Canon EOS R50").
    4. Set the driver to WinUSB and click Replace Driver (takes a minute).
    5. Unplug and replug the camera, reload this page, then Connect.

    Early test, no Zadig: try pb4u-windows-camera-test.zip (unzip, double-click "Run camera test", send us the text it shows). It uses Windows' own camera driver; if this works, Windows won't need the driver switch.

    To switch back: Device Manager → find the camera (under "Universal Serial Bus devices") → right-click → Uninstall device, tick "Delete the driver", then unplug and replug.
