USB camera test · Windows

Checks that the booth can control your Nikon, Canon EOS or Sony Alpha from this laptop: live view, the real shutter (flash works) and the full photo. Uses the photobooth4u Helper and Windows' own camera driver, so there's nothing to install for the camera itself.

Before you start

  1. Open the photobooth4u Helper (latest is 1.1.10; Canon needs 1.1.5+, Sony 1.1.9+) on this laptop. Download it, unzip, double-click. Keep its window open.
  2. Plug the camera straight into the laptop with a data USB cable (many micro-USB cables only charge) and switch it on. Windows lists it under This PC and in Device Manager under Portable Devices (not under "Cameras").
  3. Close camera apps (EOS Utility, EOS Webcam Utility, NX Studio, Nikon Webcam Utility, Sony Imaging Edge / Camera Remote) and any "Import photos" window that popped up.
  4. Camera: mode dial on P, S, A or M (Canon: P, Tv, Av or M), lens cap off, SD card in, battery charged (or a mains adapter), Auto power off disabled.
  5. Canon: on older models (60D, 70D, 600D, 7D…) turn on Live View shoot in the camera's menu. Models with Wi-Fi: turn Wi-Fi off. Newer models with a "Choose USB connection app" menu: Photo Import / Remote Control.
  6. Nikon with SnapBridge: turn on Airplane mode.
  7. Sony Alpha (A7 III, A7 IV, A6400, ZV-E10…): MENU > Setup > USB > USB Connection: PC Remote (not Mass Storage or MTP), and leave Still Img. Save Dest. on PC Only if you see it. Mode dial on a photo mode (not video). The tester sets the save destination to PC only for you, so no memory card is needed.
  8. If you ever used Zadig on this camera, undo it: Device Manager → the camera (under "Universal Serial Bus devices") → Uninstall device, tick "Delete the driver", unplug and replug.
