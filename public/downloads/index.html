Print Helper

Optional companion for this computer.

Version 1.1.10

Print directly to the right printer

The helper lets the booth send prints to a selected installed printer without a print dialog. Configure paper, quality, media type, and cutting in the printer’s own driver settings. Windows also supports Nikon, Canon EOS and Sony Alpha cameras over USB, and on a Mac it lets the booth open a USB camera that macOS is holding.

Set up printing

  1. Install the printer’s manufacturer driver and make a test print from the computer.
  2. Open the booth’s printer settings action to configure that printer’s own paper, quality, and media options.
  3. In the booth, select a printer for each paper size and test a print. Enable automatic printing only when the test looks right.
  4. For 80 mm Bluetooth thermal printers (Xprinter XP-80C, Epson TM-T82X), pair via Bluetooth and add as a system printer. On tablets, connect directly over Bluetooth or use the Android kiosk wrapper.
  5. For two sizes on one printer, add it twice in your computer’s printer settings and save separate defaults with clear names.

Start the helper

  1. Download and unzip the matching helper build.
  2. On Mac, right-click the app and choose Open the first time; approve it in Privacy & Security if prompted.
  3. On Windows, choose More info → Run anyway if SmartScreen appears.
  4. Keep its window open. In the booth, enable Print Helper on this computer and allow local network access if your browser asks.

Using a camera over USB?

USB camera support depends on the computer, camera model, and browser.

  • On Mac and Android, connect the camera and choose it in the booth’s Camera menu when the browser supports it.
  • On Windows, the helper supports Nikon and Canon EOS cameras. Close EOS Utility before using a Canon camera; older Canon models may need Live View enabled.
  • Test your camera before the event. For Windows cameras, use the Windows camera test.

Android tablet app

Works without internet and prints straight from the tablet.

Android 7.0+ · Tablet APK · version 1.0.109

Run the booth on an Android tablet

The booth runs full screen and works without internet at the venue. The tablet stays awake and the camera opens without asking each time. Unlock it with your normal access code.

Orientation: Lock to landscape or portrait in Admin, or allow either so renters can choose orientation directly on the tablet booth setup.

Printing: the tablet finds your printer by itself, over Wi-Fi or a USB cable, and prints without a pop-up. It works with most Wi-Fi printers from Epson, Canon, HP and Brother (any that support AirPrint or Mopria, which most recent models do), receipt printers, and some older Epson and Canon USB printers. You can choose colour or black and white, quality and paper type. Any other printer can print through Android’s own print screen. A few printers (some older USB-only inkjets, DNP and HiTi) still need a laptop. Printing guide • Keychain guide • Keychain PDF • Receipt booth PDF guide • Samsung Tab A + Canon SELPHY guide →

Camera: plug a Nikon, Canon EOS or Sony Alpha camera, or a USB webcam (Logitech Brio 4K, C270, C920 and other UVC webcams), into the tablet with a USB cable and pick it in the Camera list. (Sony: set USB Connection to PC Remote. Canon and Nikon: use PTP / remote mode.)

Using with your access code

The app works fully offline, so you don’t need internet at the venue. Connect to Wi-Fi or a phone hotspot once to unlock your code. After that it works without internet.

Installing on Android

Download the APK on your tablet, tap it in your notifications or Files app, and choose Install. If prompted, allow "Install unknown apps" for your browser or file manager.

Updating: from version 1.0.109, open Setup › Share › App updates on the tablet and tap Check for updates. Older versions: install the new APK from this page over the old one. Your activation, designs and photos stay.

Rush ID Station

Self-service rush ID photos and photo printing, as its own app.

New · Tablet app · version 1.0.1

Rush ID Station for tablets

Customers take or bring their own photo (USB drive, SD card, Bluetooth or a phone QR code), get a plain-background ID photo in the size they need (1×1, 2×2, passport and more), and print it. Its cameras and printers are the same as the booth’s: webcams, DSLR and mirrorless over USB, and the same printer connections.

Needs a code with Rush ID station switched on. Ask us to turn it on for your access code, then enter that same code in the app. It also needs an internet connection to check the code. Printing must be switched on for your code too (paper sizes are set in the same place as for the booth).

No tablet? On a laptop, open photobooth4u.netlify.app/rush and enter your code.

Download APK
Installing

Download the APK on your tablet, tap it in your notifications or Files app, and choose Install. If prompted, allow “Install unknown apps” for your browser or file manager. It installs beside the photobooth app and does not replace it.

Updating: download and install the newest APK from this page over the old one. Your settings stay.
