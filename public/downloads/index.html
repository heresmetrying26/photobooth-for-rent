photobooth4u Helper

Optional. Lets the booth print straight to the right printer for each paper size (for example 2×6 strips on one printer, 4R on another), with no print dialog. Without it, the booth still prints through the normal print dialog.
Windows: the helper also connects a Nikon camera over USB (live view + the real shutter), see below.

Step-by-step printer guides:
🖨️ How to print on DNP → 🖨️ How to print on HiTi →

1 · Set up the printers (once)

  1. Install each printer's driver and do one test print from the computer.
  2. The helper (1.1.6 or newer) tells the printer the paper size you pick in the booth, borderless when the printer has it. Set anything else, like the cut option for 2×6 strips, in the printer's own preferences: a printer already set to the right size keeps its settings.
  3. Same printer for two sizes (e.g. 4×6 and 2×6 cut)? Add the printer to the computer twice and give each copy its own defaults and a clear name, like HiTi 4x6 and HiTi 2x6 cut.

2 · Start the helper

  1. Mac: unzip, then right-click → Open the first time (macOS warns about apps from the internet; if it still refuses, go to System Settings → Privacy & Security and click Open Anyway). A Terminal window opens and lists your printers.
  2. Windows: unzip and double-click. If Windows shows "Windows protected your PC", click More info → Run anyway. A window opens and lists your printers.
  3. Keep that window open while the booth is running. Closing it stops the helper.

3 · Turn it on in the booth

  1. In the booth's Print box, switch on Print Helper on this computer. If Chrome asks to let the site access devices on your network, click Allow.
  2. For each paper size, pick its printer from the list under Printer for … (the booth remembers it on this computer).
  3. Print once to test. From then on prints, including Auto-print, go straight to the right printer.

The helper only accepts prints from photobooth4u and only from this computer. Chrome or Edge recommended.

Using a DSLR / mirrorless camera over USB?

The booth's USB camera mode uses the camera's real shutter, its own settings and flash.

  1. Mac or Android tablet/phone (Chrome or Edge): nothing to install. Plug the camera in and pick it in the booth's Camera menu.
  2. Windows laptop, Nikon or Canon EOS camera: open this helper (Canon needs version 1.1.5 or newer), plug the camera in with a data USB cable and switch it on. In the booth, pick Nikon / Canon camera over USB in the Camera menu once (allow Chrome's prompt). After that the booth picks the camera by itself whenever it's plugged in. No Zadig or driver change.
  3. Canon EOS: close EOS Utility first. On older models (60D, 70D, 600D…) turn on Live View shoot in the camera's menu. Canon on Windows is new: run the Windows camera test before an event.
  4. Windows with Sony: not yet. Use a Mac / Android tablet, an HDMI-to-USB capture card, or the camera's webcam mode.

Test your camera first on the camera test page.
