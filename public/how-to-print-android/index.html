Printing guide · Android tablet app 1.0.35

How to print
from the Android app

The tablet finds printers on your Wi-Fi and on its USB port by itself, then prints straight to the one you pick, with no print dialog. Works with Epson, Canon, HP and Brother printers that support AirPrint / Mopria, and with receipt printers.

Part 1 · Check first

What the tablet can print to

PrinterHow it connects
Epson, Canon, HP, Brother (everyday inkjet and laser)Wi-Fi, if the printer supports AirPrint / Mopria / IPP. The tablet finds it and prints photos without a dialog.
Canon Selphy (CP1300, CP1500)Wi-Fi, same as above.
80 mm / 58 mm receipt printersBluetooth, Wi-Fi / network, or USB. See the thermal guide.
Newer USB printers that support IPP-over-USBUSB cable to the tablet.
Older USB-only Epson inkjets (for example L120, L210)Experimental. The tablet reads the printer’s own ID. An L120 speaks Epson’s ESC/P2 language, so it is listed as a photo printer that prints in black & white on plain paper with 3 mm side borders. A Colour (experimental) choice appears in its settings; it is still being tested and leaves a blank strip at the top. Run a Test print first; for dependable quality and colour use the laptop app, or the laptop as a print station.
DNP, HiTi, Citizen, Mitsubishi, SinfoniaUse the laptop app or the Print Helper (USB drivers).

Good to know

Some printers only accept secure (ipps) printing, or only their own file formats. If the booth says so, it opens the Android print dialog instead, or you can use the laptop.

Part 2 · Wi-Fi

Find and pick the printer

The tablet and the printer must be on the same Wi-Fi. A router with guest or “client isolation” switched on will hide the printer.

  1. 1

    Connect both to the same Wi-Fi

    Join the printer to the Wi-Fi (most printers have a wireless setup button), then join the tablet to the same network.

  2. 2

    Open Print settings

    In the app go to Setup → Print settings, choose your paper size, then find the Wi-Fi printer section.

  3. 3

    Find Wi-Fi printers

    Tap Find Wi-Fi printers. After about 10 seconds your printer appears with its model name. Tap it to choose it. If it is missing, type the printer’s IP address (from its network status page) in the box and tap Add.

  4. 4

    Print a test

    Take a test photo and print. It goes straight to the printer. If it cannot, the booth tells you why and opens the Android print dialog.

Settings

Colour, quality and paper type

After you pick a printer, the app shows only the settings that printer says it supports.

SettingWhat you can choose
ColourColour or black & white, on printers that offer both. On an Epson L120, black & white is the dependable one.
QualityDraft, Normal or High, on Wi-Fi printers that support it. Printer default if you leave it.
Paper typePlain or photo paper, if the printer lists it. Leave on printer default if unsure.
Paper sizeChosen in Print settings, the same as for every printer. The printer gets that size with no borders when it supports it.

Good to know

If a printer refuses a setting, the app sends the photo again without it, so printing still works.

Part 3 · USB

Plug a printer into the tablet

The tablet needs USB host (OTG) support and a cable or adapter that fits its port.

  1. 1

    Plug it in

    Connect the printer and switch it on. Open Print settings → Wi-Fi printer: the USB printer appears in the list by itself.

  2. 2

    Allow USB access

    Android asks Allow photobooth4u to access the USB device? Tap OK.

  3. 3

    Pick it

    Tap the printer. A printer marked no driver is detected but needs its own driver, which the tablet app does not have. Use the laptop for that one.

Experimental · help us test

Epson L120 over USB

These older ink-tank printers have no Wi-Fi. App 1.0.35 can try to print to them from the tablet, but this is still being tested, so do not rely on it for an event yet.

  1. 1

    Load plain paper

    Put plain A4 or 4×6 paper in the printer and switch it on.

  2. 2

    Plug it into the tablet

    Use a USB cable and an OTG adapter, then tap OK when Android asks to allow USB access.

  3. 3

    Pick it

    In Print settings → Wi-Fi printer the printer should appear as photo (experimental). If it says no driver, the printer did not report Epson’s ESC/P-R language and the app will not send it anything.

  4. 4

    Tap Test print

    You should get one test sheet with a border, in black and white. If you get pages of letters and symbols instead, stop and tell us.

  5. 5

    Tell us what happened

    Message us with the printer model and what came out: nothing, a blank page, strange lines, or a clear print.
