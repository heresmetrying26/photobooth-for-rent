Part 1 · First time setup

Install the DNP Printer on your computer

On Windows (Recommended for DNP)

  1. Download the official DNP Windows Driver for your model (e.g. DS-RX1HS Driver or DS620 Driver) from DNP's official support website.
  2. Run the installer and follow the prompt. When asked, plug in the DNP's USB cable and turn the power on.
  3. Open Settings → Bluetooth & devices → Printers & scanners. Click your DNP printer → Printing preferences.
  4. Under Paper / Quality, verify paper size is 4x6 (102x152mm) or 6x4, and Orientation is set properly.
  5. Under Printer properties, rename the printer to DNP 4x6 so it's easy to identify.

On Mac (macOS Big Sur 11, Monterey 12, Ventura 13, Sonoma 14, Sequoia 15)

  1. 1

    Install DNP Mac OS Driver

    Download the official DNP macOS driver (CUPS driver) for your model from DNP's website, install the package, and restart your Mac.

  2. 2

    Add the Printer

    Open System Settings → Printers & Scanners → Add Printer. Select your DNP printer. Ensure the Use dropdown shows the official DNP driver (not Generic PostScript). Name it DNP 4x6 → click Add.

Part 2 · The 2×6 photo strip setup

Add the DNP a second time for 2×6 strip cuts

Photobooth layouts with 2×6 strips automatically place two strips side-by-side on one 4×6 sheet. DNP printers have a physical blade inside that cleanly cuts the sheet into two 2×6 strips when the 2-inch cut setting is enabled!

On Windows: Adding the "DNP 2x6 Strips" queue

  1. Open Control Panel → Devices and Printers (or run control printers).
  2. Click Add a printer → click The printer that I want isn't listed.
  3. Select Add a local printer or network printer with manual settings → Next.
  4. Choose Use an existing port: pick the exact USB port your DNP is plugged into (e.g., USB001 (Virtual printer port for USB)) → Next.
  5. Select manufacturer DNP and pick your model's driver → select Use the driver that is currently installed (recommended) → Next.
  6. Name the printer: DNP 2x6 Strips (or DNP 2x6 Cut) → Finish.
  7. Right-click DNP 2x6 Strips → Printing preferences → find Option / Advanced:
    Enable "2-inch cut" (or "2 inch cut: Cut" / "Multi-cut: 2-inch cut") → click OK.

On Mac: Adding the 2-inch cut queue via CUPS

  1. 1

    Add the printer again

    In Printers & Scanners, click Add Printer again, pick the same DNP, and name it DNP 2x6 Strips.

  2. 2

    Enable CUPS Web Interface

    Open Terminal and run:

    cupsctl WebInterface=yes

    Then open http://localhost:631/printers in Safari or Chrome.

  3. 3

    Set 2-inch Cut Option

    Click on DNP 2x6 Strips → from the Administration dropdown, select Set Default Options → under Media / Page Size, select the 2-inch cut option (often named (2) 2x6" cut, w288h432-div2, or 4x6 2-cut) → click Set Default Options.

Part 3 · Inside photobooth4u

Choose your DNP printers in the booth

Once both queues are created, the booth switches between 4R sheets and 2×6 cut strips automatically. No manual driver switching during events!

  1. 1

    Open the Booth

    Open the offline desktop app (or open photobooth4u.netlify.app in Chrome with the Print Helper running).

  2. 2

    Open Print Settings

    In Photo Session, tap the 🖨 Print settings button at the bottom left.

  3. 3

    Assign Each Paper Size

    Pick the dedicated printer for each layout format:

Paper Size FormatSelected PrinterWhat the DNP Does
4R (4×6)DNP 4x6Prints 1 full 4×6 photo sheet, no cut
4R · strip layouts (2 strips, cut)DNP 2x6 StripsPrints and cuts into two separate 2×6 strips

Part 4 · Before the event starts

Test both sizes, then turn on Auto-print

1

Test 4R (4×6)

Take a test session with a 4R layout and hit Print. Verify a crisp, full-bleed 4×6 photo ejects without white borders.

2

Test 2×6 Strips

Switch to a classic 3-photo or 4-photo strip layout and hit Print. The DNP will print and automatically slice it into two 2×6 strips.

3

Turn on Auto-Print

Tick "Auto-print every session" in Print Settings. Now, every guest session automatically prints as soon as photos are taken!

Troubleshooting

DNP Quick Fixes

SymptomQuick Solution
Strips print on 4×6 but aren't cutThe strip layout is printing to DNP 4x6 instead of DNP 2x6 Strips, or the 2-inch cut option wasn't saved in preferences. Go to booth Print Settings and ensure 4R strip layouts is assigned to DNP 2x6 Strips.
Flashing Red LED on DNPFlashing red means ribbon or paper issue: open the front hatch, tighten the ribbon spools (remove any slack), ensure the paper roll's scrap box is emptied, and snap the lever back firmly.
Thin white border on edgeIn DNP printing preferences, check Overscan / Borderless to ensure full-bleed printing is activated.
Printer says "Paused" or "Offline"Unplug and re-plug the USB cable, or restart the DNP. Check Windows / Mac print queue to resume.

iPad & Tablet Operators

Using DNP with an iPad / Tablet Booth

How to print from iPad to DNP (No AirPrint needed!)

DNP printers do not natively have Apple AirPrint. But photobooth4u has a built-in Laptop Print Station:

  1. Plug the DNP printer into any laptop (Windows or Mac) via USB.
  2. Open the photobooth4u app (or Print Helper) on that laptop.
  3. Connect both the laptop and the iPad to the same booth Wi-Fi router (or the laptop's mobile hotspot).
  4. On the iPad booth, go to Print settings → select the laptop as the Print Station. Every print from the iPad sends instantly over Wi-Fi and silently prints to the DNP!
