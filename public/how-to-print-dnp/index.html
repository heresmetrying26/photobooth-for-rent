Choose Your 2×6 Mode · Windows & Mac

Dual-Queue vs. Single-Queue Auto-Split

photobooth4u supports both workflows automatically. Use Dual-Queue on Windows for 100% reliability across every DNP driver version, or Single-Queue Auto-Split when your driver already lists split paper sizes (common on macOS CUPS and newer drivers).

Option A · Dual-Queue Driver Best Default on Windows

Install the same DNP twice on the exact same USB port: DNP 4x6 (uncut) and DNP 2x6 Strips (2-inch cut enabled).

  • Required when 2-inch cut is a driver checkbox (most Windows DS-RX1HS, DS620A & DS40 drivers store 2-inch cut under Layout → Advanced rather than as a separate paper size).
  • Independent tuning per mode: separate Lightness, Colour Balance, Edges, and Glossy/Matte finish for 4×6 vs 2×6 strips.
  • Uses photobooth4u's warm background Windows print worker (zero cold PowerShell delay) while preserving private DNP driver settings.

Option B · Single-Queue Auto-Split Fastest on Mac

Keep just one printer queue (e.g. DNP DS620 or DNP DS-RX1). Works whenever your driver lists both 4x6 and a split slot (e.g. w288h432-div2, PR (4x6)*2, 4x6 2-cut, (2) 2x6" cut) or a macOS CUPS cut option.

  • No duplicate printer queue needed.
  • photobooth4u switches to the split slot for 2×6 strip layouts and back to uncut 4×6 for full-sheet layouts automatically.
  • QW410 users: always use a single queue (load perforated PD-2S 4×6 media — no cutter option exists).

Option C · DNP Hot Folder Print Zero Spooler · Pro

Already run DNP's official Hot Folder Print (HFP) app on Windows or Mac? Connect it directly inside photobooth4u under Find a Wi-Fi, USB, Bluetooth, Hot Folder, or Instax printer → DNP Hot Folder Print.

  • 1-click auto-detect finds standard folders (e.g. C:\DNP\Hot Folder\Prints\4x6, 2x6, or macOS ~/Documents/HotFolderPrint/Prints/).
  • Atomic file drop (.tmp → rename) bypasses the Windows/Mac print spooler completely, preserves DNP ICC profiles, and unlocks DS620A panoramics (6×14, 6×20).
  • Appears as Hot Folder: DNP 4x6 / Hot Folder: DNP 2x6 — works with Printer 1, 2×6 Split Strips Printer, Auto-Print, and Offline Laptop Print Station!

Option D · Desktop Direct-USB No Driver · Beta

On a fresh Windows or Mac laptop with no DNP driver installed yet, the Laptop App can print straight over USB to DS-RX1 / RX1HS, DS620 / DS620A, and DS40.

  • Plug in USB → click Find Wi-Fi / USB printers → pick DNP DS-RX1 (USB direct).
  • No driver, no second 2×6 queue, Glossy/Matte selectable under Paper Type, plus live low-media alerts from the printer's roll counter.
  • If you install DNP's official driver later, the app automatically prefers the official driver queue for factory ICC colour accuracy.

Step 1 · One-time setup on your laptop

Install the DNP Driver (Best-Practice Order)

Always download the official driver from DNP's support site — never use Windows Generic or Apple Generic PostScript drivers. Install the driver before plugging in the USB cable.

Windows 10 / 11 (Recommended for Events)

  1. Unplug the DNP USB cable first. Download and run the official DNP Windows Driver for your model (e.g. DS-RX1HS, DS620A, DS40, QW410). Restart if prompted.
  2. Plug directly into a laptop USB port (no unpowered USB hub; keep cable ≤ 2 m / 6 ft) and power the printer ON. Always use this exact same physical USB port at events so Windows doesn't create a duplicate "Copy 1" printer.
  3. Open Control Panel → Devices and Printers (press Win + R, type control printers, Enter). Right-click your DNP → Printer properties.
  4. On the General tab, rename it DNP 4x6 (always keep DNP, DS620, RX1, or QW410 in the name). Click Preferences…:
    • Paper Size: PR (4x6) or 4x6 (102x152mm)
    • Print Mode / Quality: High-Speed (300×300 dpi) — avoid 300×600 High-Res, which nearly doubles print time
    • Finish / Overcoat: Glossy (fastest) or Matte
    • 2-inch cut: Disable → Apply & OK.
  5. Windows 11 Fail-Safe: In the same Printer properties window, open the Advanced tab → click Printing Defaults… and apply the exact same 4×6 / High-Speed / Disable 2-inch cut settings so Windows updates never reset them.

macOS (Apple Silicon & Intel · macOS 11–15+)

  1. Download and install the official DNP macOS CUPS driver for your model from DNP's website, then restart your Mac.
  2. Load matching paper & ribbon, plug the DNP directly into your Mac via USB, and turn it on.
  3. Open System Settings → Printers & Scanners → Add Printer. Select your DNP printer, confirm Use shows the official DNP driver (never Generic PostScript), name it DNP 4x6, and click Add.
  4. Fastest way to configure on Mac: In the photobooth4u Laptop App, select DNP 4x6 and click Configure printer — the app shows your DNP's PPD options (Page Size, Finish, Cutter) right inside the booth with no Terminal commands needed.
  5. Using two DNP printers on one Mac? Enable iSerial in DNP's printer utility so macOS keeps each queue locked to the right unit across reboots.

Pro Rule: Keep “DNP” (or the Model Code) in the Printer Name

Names like DNP 4x6, DNP 2x6 Strips, DP-DS620, DS-RX1HS, or DP-QW410 automatically activate photobooth4u's dedicated dye-sub print engine — locking your private driver cut/finish/color settings in place and preventing accidental inkjet scaling or white borders.

Step 2 · 2×6 photo strip auto-cut setup

Add the “DNP 2x6 Strips” Queue (Dual-Queue Mode)

DS620 / DS620A, DS-RX1 / DS-RX1HS, and DS40: follow these steps once for rock-solid automatic strip cutting. (Skip this step if you have a QW410 — it uses perforated PD-2S media on your single queue — or if you are using macOS Single-Queue Auto-Split or Android Direct USB.)

Windows: Add DNP 2x6 Strips on the Same USB Port

  1. Open Control Panel → Devices and Printers (run control printers). Check which USB port DNP 4x6 uses under Printer properties → Ports (e.g. USB001).
  2. Click Add a printer → click The printer that I want isn't listed.
  3. Select Add a local printer or network printer with manual settings → Next.
  4. Choose Use an existing port → pick that exact same USB port (e.g. USB001 (Virtual printer port for USB)) → Next.
  5. Pick manufacturer DNP and your model → choose Use the driver that is currently installed (recommended) → name it DNP 2x6 Strips → Finish.
  6. Right-click DNP 2x6 Strips → Printer properties:
    • General → Preferences… → Layout: Paper Size PR (4x6) → click Advanced… → set 2inch cut (or 2-inch cut / Multi-cut) to Enable → OK.
    • Advanced tab → Printing Defaults…: set the exact same 2inch cut: Enable + High-Speed (300×300 dpi) → Apply & OK.

macOS: Configure 2-Inch Cut (In-App or CUPS)

  1. Try Single-Queue Auto-Split first: On most DNP macOS drivers, photobooth4u detects w288h432-div2 / (2) 2x6" cut / 4x6 2-cut and switches automatically with just DNP 4x6. Run Test 2×6 strips (cut) in Step 4 to check!
  2. Or add a dedicated 2nd queue: In System Settings → Printers & Scanners, click Add Printer again, pick the same DNP, and name it DNP 2x6 Strips.
  3. In Laptop App: Select DNP 2x6 Strips under 2×6 Split Strips Printer → click Configure 2×6 printer → pick the 2-inch cut Page Size or Cutter option → click Save printer settings.
  4. In Chrome + Print Helper (CUPS fallback): Run in Terminal, then open http://localhost:631/printers (sign in with your Mac username & password):
    cupsctl WebInterface=yes
    Click DNP_2x6_Strips → Administration → Set Default Options → pick (2) 2x6" cut, w288h432-div2, or 4x6 2-cut (or enable the 2-inch cut option) → Set Default Options.

Step 4 · 20-second check before guests arrive

Test Both Modes, Turn On Auto-Print & Lock Event Stability

1

Tap “Test 4×6 whole”

Inside 2×6 Split Strips Printer, tap Test 4×6 whole. Confirm one crisp, full-bleed 4×6 sheet with zero white lines and accurate colour bars.

2

Tap “Test 2×6 strips (cut)”

Tap Test 2×6 strips (cut). Confirm the DNP slices cleanly down the center dashed line into two separate 2×6 strips (or aligns with the perforation on QW410).

3

Turn On Auto-Print

Under Automatic printing, turn on Print after each session (or Send a print automatically after each session). Guests get instant prints with zero operator taps.

5-Point Event-Day Efficiency Checklist (Prevents 95% of Mid-Event Issues)

  • Empty the scrap box before every event — a full scrap tray stops the cutter and triggers a flashing red LED mid-queue.
  • Plug both laptop & DNP into wall power and set Windows/macOS Sleep = Never when plugged in.
  • Disable Windows USB Selective Suspend (Control Panel → Power Options → Change plan settings → Advanced → USB settings) so the USB port never naps between quiet stretches.
  • Run 1 warmup print before doors open — the first print warms the thermal head; after that, prints stay at full rated speed (8.4s DS620A / 12.4s RX1HS).
  • Avoid double colour profiling: let the DNP driver use its factory colour table and do any minor skin-tone or brightness tweak inside photobooth4u's per-printer Lightness & Colour Correction (guests' digital QR copies stay untouched).

iPad & Tablet Booths · Zero Internet Needed

Using a DNP Printer with an iPad (or Android Tablet)

Bare DNP printers do not have built-in Wi-Fi or Apple AirPrint, and iPads cannot load Windows/Mac USB printer drivers. photobooth4u gives you three seamless options — starting with our built-in Offline Laptop Print Station (zero internet, zero extra hardware).

Method 1 · Offline Laptop Print Station Recommended · Zero Internet

Print silently over a travel Wi-Fi router or Windows Mobile Hotspot with a 6-Digit PIN. Works on iPad & Android apps with DS620A, RX1HS, DS40, QW410, DS80, and DS820A.

  1. Connect the DNP to your Windows/Mac laptop via USB (Steps 1 & 2 done).
  2. On the laptop, open Offline Print Station inside Laptop App 1.1.112+ (Setup bottom bar → ⋯ → Offline Print Station) — OR run standalone Print Helper 1.1.25+ (uses 0 license slots!).
  3. Turn on your travel router or click Turn On Booth Hotspot, tick only your DNP queues (click Hide unused), and run a test print.
  4. On your iPad/Android app: join that Wi-Fi → open Setup → 4 Printer → turn ON Laptop Print Station (Wi-Fi · Offline USB printer) → tap Find Laptop on Wi-Fi → enter the 6-Digit PIN → pick DNP 4x6 & DNP 2x6 Strips!

Need step-by-step screenshots & DSLR tips? See the full Offline Print Station guide →

Method 2 · DNP WCM Plus No Laptop · Hardware AirPrint

Already own a DNP WCM Plus wireless print server? It plugs into up to 3 DNP printers (DS-RX1HS, DS620A, QW410, DS820A, DS40, DS80) and turns them into standard Apple AirPrint printers.

  1. Plug your DNP printer(s) into the WCM Plus USB ports and join your iPad to the WCM Plus Wi-Fi (or bridge WCM Plus to your venue router for simultaneous internet sharing).
  2. Configure 4×6 / 2×6 cut queues in the WCM Plus web portal.
  3. In the photobooth4u iPad app (Setup → 4 Printer), tap Pick Silent AirPrint printer and pick your WCM Plus DNP queue once — prints go out with zero AirPrint pop-ups!

Method 3 · Cloud Print Station Online · Different Wi-Fi Networks

Use this when the tablet runs on cellular/hotspot and the laptop is on a separate internet connection (or when running the web booth in Safari/Chrome).

  1. On the laptop plugged into the DNP, start the Print Helper and open photobooth4u.netlify.app/print-station/, then sign in with your booth code (uses 0 extra device slots).
  2. Pick your DNP printers right on the page: 4R (4×6) → DNP 4x6 and 4R (4×6) · 2×6 strips (cut) → DNP 2x6 Strips. Choose Auto-print or Queue & view first, then tap Test 4×6 whole and Test 2×6 strips (cut).
  3. On your iPad or Android tablet booth, open Setup → 4 Printer → Send prints to → Send to a laptop print station.

Troubleshooting

DNP Quick Fixes

SymptomFastest Fix
Strips print on 4×6 but aren't cut In photobooth4u, expand Multiple printers & 2×6 strip cutter and verify 2×6 Split Strips Printer is set to DNP 2x6 Strips. On Windows, open DNP 2x6 Strips → Printer properties and confirm 2inch cut: Enable is saved in both Preferences and Advanced → Printing Defaults. (QW410 has no cutter — use perforated PD-2S media.)
Whole 4×6 photo gets cut in half Open DNP 4x6 → Printing preferences & Printing Defaults and set 2inch cut to Disable. In Single-Queue mode, check Driver paper size / slot under Printer 1 is on Auto match or uncut 4x6.
Thin white border on one edge (or edge slightly cropped) Confirm the printer queue name includes DNP (or DS620 / RX1 / QW410) and borderless/overscan is enabled in the driver. Then open Print settings → Edges (margins) and tap Print edge test:
• Thin white line on a side: press − (minus) to push the image outward (0.5 mm per tap).
• Side slightly cut off: press + (plus) to pull the image inward.
Prints are slow (~20–30 sec on DS620A / RX1HS) Check driver Print Mode in Printing Preferences & Printing Defaults: switch from High-Resolution (300×600 dpi) back to High-Speed (300×300 dpi). Also plug USB directly into the laptop (remove passive USB hubs or cables over 2 m).
Flashing Red LED on DNP Open the front hatch, tighten any slack in the ink ribbon spools, empty the paper scrap box, ensure the paper flanges sit flush on the roll, and close the door firmly until it latches.
Windows created “DNP (Copy 1)” or printer shows Offline The USB cable was plugged into a different physical USB port than during setup. Move the cable back to the original USB port, or update the port on both DNP 4x6 and DNP 2x6 Strips under Printer properties → Ports.
Prints look slightly dark, warm, or washed out Open Lightness & Colour Correction inside that printer's card in photobooth4u (independent per printer!) and nudge Lightness (e.g. +10 to +20) or colour balance. Digital/QR copies stay unchanged. Avoid enabling ICC colour management in two apps at once.
Android: DNP isn't listed or asks for USB access Confirm Android app is 1.1.10+, printer is ON, and your USB-C cable/adapter supports OTG data (charge-only cables won't work). Tap Refresh printer list, tap the DNP, tick Always open, and tap OK.
Android: “Paper definition error” or “Paper/Ribbon end” Match the booth's paper size to the physical media roll installed (e.g. 4R for 4×6 media). For paper/ribbon end or cover open, reload matching paper + ribbon and latch the front door firmly.
