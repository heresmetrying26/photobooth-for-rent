How to print
on the HiTi

Set up once, about 20 minutes. After that every session prints by itself: 4×6 photos on one setting, and 2×6 strips cut in two on the other. Do the test in Part 5 before the event.

Using the Android tablet app?

The Android app prints to Bluetooth thermal receipt printers (see the thermal printer guide). A HiTi needs a Windows or Mac laptop running the laptop app or the Print Helper, so use a laptop for HiTi prints.

Part 1 · Once

Install the HiTi on the Mac

  1. 1

    Install the driver

    Download the macOS driver for your HiTi model from HiTi’s website, install it, then restart the Mac.

  2. 2

    Connect it

    Turn the HiTi on, load the ribbon and paper, and plug its USB cable into the Mac.

  3. 3

    Add it to the Mac

    System Settings → Printers & Scanners → Add Printer. Select the HiTi and check that Use shows the HiTi driver, not “Generic”. Name it HiTi 4x6 → Add.

  4. 4

    Test it

    Print any photo from the Preview app at 6×4, borderless to check the printer works.

On Windows

  1. Install the Windows driver for your HiTi model from HiTi’s website, then plug in the printer.
  2. Settings → Bluetooth & devices → Printers & scanners: the HiTi appears. Open it → Printing preferences → paper 6×4, borderless → OK. Rename it HiTi 4x6 under Printer properties.
  3. Print one photo from the Photos app to test.

Part 2 · Only if you print strips

Add the same HiTi a second time

The booth puts two 2×6 strips side by side on one 4×6 sheet, and the HiTi cuts the sheet in half. So the Mac needs a second copy of the printer with the cut switched on.

  1. 1

    Add it again

    Add Printer again, choose the same HiTi, name it HiTi 2x6 cut → Add. Now you have two printers that are really one machine.

  2. 2

    Open the printer settings page

    Open Terminal and run this, then open localhost:631/printers in Chrome. If it asks for a username and password, use your Mac’s login.

    cupsctl WebInterface=yes
  3. 3

    Set each printer’s paper

    Click HiTi 4x6 → Administration → Set Default Options: Media Size 6x4, borderless if listed → save.
    Click HiTi 2x6 cut → Set Default Options: the 2-inch cut paper option (named like “6x4 (2x6 ×2)” or “6x4 Split”, depending on the model) → save.

On Windows

  1. Control Panel → Devices and Printers → Add a printer → The printer that I want isn’t listed → Add a local printer… with manual settings.
  2. Use an existing port: pick the HiTi’s USB port (the same one the first HiTi uses, e.g. USB001) → choose the HiTi driver → Use the driver that is currently installed → name it HiTi 2x6 cut.
  3. Right-click HiTi 2x6 cut → Printing preferences → choose the 2-inch cut paper option → OK.

Part 3 · Every event

Open the Print Helper

The small app that lets the booth print straight to the right printer, with no pop-up. Always open the booth from photobooth4u.netlify.app (not a saved copy of the page): the helper only answers that address.

  1. 1

    Download it once

    From photobooth4u.netlify.app/downloads/: Mac · Apple Silicon or Intel. Unzip it.

  2. 2

    Open it

    Mac: the first time, right-click → Open. If macOS blocks it: System Settings → Privacy & Security → Open Anyway.
    Windows: double-click it. If you see “Windows protected your PC”: More info → Run anyway.

  3. 3

    Keep its window open

    A Terminal window opens and lists your printers. Leave it open during the whole event; closing it stops printing.

photobooth4u Print Helper 1.0.0
Running. Keep this window open while the booth is printing.
Printers on this computer:
 - HiTi_4x6
 - HiTi_2x6_cut

Part 4 · In the booth

Choose the printers

  1. 1

    Open Print settings

    In Photo Session, tap 🖨 Print settings at the bottom left.

  2. 2

    Turn on the Print Helper

    Switch on Print Helper on this computer. If Chrome asks to access devices on your network, click Allow.

  3. 3

    Pick a printer for each size

    Tap a paper size, then choose its printer from the list. The booth remembers it on this Mac.

Paper sizeChoose
4R (4×6)HiTi_4x6
4R · strip layouts (2 strips, cut)HiTi_2x6_cut

Part 5 · Before the event

Test both, then Auto-print

1

A 4R layout

Take a session → Print. Expect a full 4×6 with no white border.

2

A strip layout

Take a session → Print. Expect two 2×6 strips, already cut.

3

Auto-print on

Both right? Tick Auto-print every session. Every session now prints by itself.

If something’s wrong

Quick fixes

ProblemFix
“Can’t reach the Print Helper”See the steps below.
HiTi isn’t in the printer listCheck it’s on and plugged in, then close and reopen the Print Helper.
Strips print but aren’t cutThe cut option isn’t saved as the default for HiTi 2x6 cut. Redo Part 2, step 3.
White border or wrong sizeFix the paper size and borderless setting in that printer’s Set Default Options (Part 2).
Printer shows “Paused”System Settings → Printers & Scanners → the HiTi → Resume. Check the ribbon and paper.
No cut option in the listRun lpoptions -p HiTi_2x6_cut -l in Terminal and send us the result. We’ll reply with the one line that sets it.

Print Helper

If the booth can’t reach the Print Helper

The helper window lists your printers, but the booth says “Can’t reach the Print Helper”. Go through these in order:

  1. 1

    Use the real booth address

    Open the booth from photobooth4u.netlify.app. A saved copy of the page (an address starting with file://) or another address won’t connect.

  2. 2

    Chrome or Edge: allow local network access

    Click the icon at the left of the address bar → Site settings → Local network access → Allow. If a pop-up asks to “look for and connect to devices on your local network”, click Allow.

  3. 3

    Brave: lower the Shields

    Click the lion icon at the right of the address bar and turn Shields off for photobooth4u. If Brave asks to let the site access localhost, click Allow.

  4. 4

    Check again

    Reload the booth, open Print settings, and switch Print Helper on this computer off and on (or tap Check again). The checklist at the top turns green when it’s connected.

Only printing 4×6? The simple way

Skip Parts 2 and 3. Make the HiTi the Mac’s default printer, do one normal print, then start Chrome with this command in Terminal so prints go out with no pop-up:

open -a "Google Chrome" --args --kiosk-printing https://photobooth4u.netlify.app/
