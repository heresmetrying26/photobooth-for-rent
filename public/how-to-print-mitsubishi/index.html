How to print
on a Mitsubishi printer

For the Mitsubishi CP-D70DW, CP-D707DW, CP-D80DW, CP-D90DW, CP-K60DW-S, CP-M1E / M1A, CP-3800DW and older CP-9000 series dye-sublimation printers. They connect by USB to a Windows or Mac laptop and print 4×6 and larger sizes. Set up once, then test before the event.

Part 1 · Check first

Where the booth works

Mitsubishi dye-sublimation printers connect by USB to a Windows or Mac laptop. The booth prints to them like any printer that has a driver.

How you run the boothWorks?
Windows / Mac laptop app (offline)Yes. Prints straight to the printer, no pop-up, no internet needed.
Windows / Mac laptop, online booth in ChromeYes. Open the Print Helper so the booth prints without a pop-up.
iPad or Android tablet booth (online)Through a laptop. Plug the printer into a laptop running photobooth4u.netlify.app/print-station/; on the tablet choose Printer → Send prints to → Laptop print station.
Android tablet app (APK)No. The Android app prints only to Bluetooth thermal receipt printers.

Choose a Windows laptop for older models

For the D70DW, D707DW, D80DW, 3800DW and older, Mitsubishi's Mac drivers are for very old macOS versions. A Windows laptop is the safer choice for them. The D90DW, K60DW-S and M1E have more recent Mac drivers.

Part 3 · Once

Install the printer

  1. 1

    Install the driver

    Download your model's driver from Mitsubishi's page above, install it, then restart the laptop.

  2. 2

    Load media

    Use Mitsubishi's media for your model: the paper and ink ribbon must be the same size (for example 4×6 and 6×8 kits are different).

  3. 3

    Connect it

    Turn it on and plug the USB cable straight into the laptop (no hub). Wait for Windows or macOS to add the printer.

  4. 4

    Set the paper and finish

    Windows: Settings → Bluetooth & devices → Printers & scanners → your printer → Printing preferences. Mac: System Settings → Printers & Scanners, then the print dialog's options. Choose the paper size for the loaded roll (for example 4×6) and glossy or matte.

  5. 5

    Test it

    Print one photo at the same paper size from the Photos app (Windows) or Preview (Mac).

Part 4 · In the booth

Choose the printer and paper

  1. 1

    Laptop app or Print Helper

    Laptop app: nothing to open. Online booth in Chrome: open the Print Helper and keep its window open. Always open the booth from photobooth4u.netlify.app.

  2. 2

    Pick a printer per paper size

    In Photo Session → Print settings, tap the paper size (for example 4×6 in or 6×8 in) and choose your Mitsubishi in the list.

  3. 3

    Auto-print (optional)

    After one good test, tick Auto-print every session.

Part 5 · If you print 2×6 strips

Photo strips

The booth puts two 2×6 strips side by side on one 4×6 sheet. The printer then needs to cut the sheet in half.

  1. 1

    Check your model

    Mitsubishi's CP-D90DW brochure lists multi-format printing from 2×6. Mitsubishi added 2×6 multi-cut to the CP-D70DW and CP-D707DW through a firmware and driver update (reported by its US dealer), so update both from Mitsubishi's download page. For other models, look for a 2 inch cut or 2×6 option in the driver.

  2. 2

    Add the printer a second time

    Add the same printer again in Windows or macOS and name it Mitsubishi 2x6 cut. In that copy's printing preferences, choose the 2×6 / 2-inch cut option. Keep the first copy on plain 4×6.

  3. 3

    Assign them in the booth

    In Print settings, give the 4×6 size the first printer and the 2×6 strips the 2x6 cut printer.

Part 6 · Before the event

Test and fixes

ProblemTry this
Printer not in the booth's listCheck it shows in Windows / Mac Printers & scanners. Reopen the Print Helper, or restart the laptop app.
Wrong size or a white borderSet the paper size in the driver's preferences to match the loaded roll; choose borderless if offered.
Only one deck prints on a two-deck modelThe D707DW has two decks. Mitsubishi notes some drivers use only one deck; load both decks and update the driver.
Driver won't install on a new laptopMitsubishi lists drivers up to Windows 10 for many models. Use a laptop on a Windows version the driver lists, or message us.
Pop-up print dialog every timeOnline booth: open the Print Helper. Or use the laptop app.
