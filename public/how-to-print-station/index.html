How it works

Separate USB camera + Wi-Fi print channels (zero conflict)

On the native iPad app, your USB DSLR talks straight to the iPad over USB, while print jobs travel wirelessly over local Wi-Fi to the laptop plugged into your dye-sub printer.

Step 1 · Pick your laptop Print Station method

  1. 1

    Admin: turn on Print Station for the client’s code

    Open Admin (/admin.html), find the client’s code (or create a new code with Built-in Print Station ticked), and click Turn on Print Station. Without this enabled, the Print Station button stays hidden and port 47777 refuses incoming tablet print connections.

  2. 2

    Open photobooth4u Desktop App 1.1.111+ on the laptop

    Plug the Mitsubishi CP-D80DW (or DNP / HiTi) into the laptop via USB with its driver installed. If asked by Windows Firewall, tick both Private and Public and click Allow access.

  3. 3

    Where to click in the Laptop App

    Either on Setup tap ⋯ (bottom right next to Profiles) → Offline Print Station (iPad / Tablet), OR in Photo Session tap Tools → Print Station. Camera preview pauses automatically while Print Station is open so the laptop stays cool and fast.

  4. 4

    Hotspot, Driver Check & Test Print

    If you have no router, click Turn On Booth Hotspot right in the Print Station header. Then click Driver Preferences to verify your loaded roll size, and click Test 4×6 or Test 2×6 Cut to test the D80 before pairing the iPad. Note the green Laptop Wi-Fi Address and yellow 6-Digit PIN.

  1. 1

    Download & extract Print Helper 1.1.24+

    Go to /downloads/#helper-builds, download the Windows (or Mac) Print Helper zip, and click Extract All into a folder (for example Desktop). Install your printer driver first (e.g. Mitsubishi CP-D80DW).

  2. 2

    Connect laptop hotspot or booth router

    On Windows, open Settings → Network & internet → Mobile hotspot and turn it on, or join a mini travel Wi-Fi router (internet is not needed).

  3. 3

    Double-click Open Laptop Print Station.bat

    This launches Print Helper and opens the clickable dashboard in Chrome/Edge at http://127.0.0.1:17321/station. Allow Windows Firewall (Private & Public) if prompted. (Inside the black Print Helper window, you can also press O + Enter anytime to reopen the page, N + Enter for a new PIN, or R + Enter to refresh printers.)

  4. 4

    Click Driver Preferences & Test Print

    Next to your Mitsubishi printer, click Driver Preferences to confirm 4×6 or 2×6 cut, then click Test 4×6 or Test 2×6 Cut. Keep both windows open during the event and turn off Windows sleep on AC power.

Step 2 · Update once, then connect offline

Where to tap on the iPad App (+ Canon 550D DSLR)

  1. 0

    One-time iPad OTA update (needs internet once)

    Open the native photobooth4u iPad app while online → tap Setup → Check for updates so it downloads the latest booth bundle over the air (no Sideloadly reinstall needed).

  2. 1

    Join the laptop’s Wi-Fi or booth router on the iPad

    Open iPad Settings → Wi-Fi and connect to the laptop’s Mobile Hotspot or booth router. If iPadOS warns “No Internet Connection”, tap Keep Trying Wi-Fi / Use Without Internet.

  3. 2

    Connect your DSLR camera (if using Canon 550D / EOS)

    Plug the Canon 550D into the iPad with a USB-C hub or Apple Lightning-to-USB 3 Camera Adapter (powered). Set the dial to M or Av, set Auto Power Off → Disable in camera menu, and select it in Setup → Camera. Live view and shutter run inside the iPad over USB with zero interference to Wi-Fi printing.

  4. 3

    Pair Laptop Print Station in Setup → Printer

    Pick your paper size (4×6 or 2×6 strips), switch ON Laptop Print Station (Wi-Fi · Offline USB printer), tap Find Laptop on Wi-Fi (or type the IP shown on the laptop), type the 6-Digit PIN, and tap Connect.

  5. 4

    Pick Printer 1 & turn on Auto-print

    Under 1 · Printer 1, pick your Mitsubishi printer (e.g. Mitsubishi CP-D80DW or Mitsubishi 2x6 cut). Turn on Send a print automatically after each session once your first test print looks right.

Ready-to-Send Client Instructions (Taglish) 
Hi Sir! Ito na po yung guide para sa Offline Laptop Print Station (iPad App + DSLR → Windows Laptop + Mitsubishi D80, kahit walang internet sa venue):

1. ONE-TIME UPDATE (kailangan muna may internet):
• Sa Windows Laptop: i-download at i-extract ang Print Helper v1.1.24 sa https://photobooth4u.netlify.app/downloads/ (or gamitin ang Desktop App 1.1.111+ kung naka-enable ang Print Station sa code mo). Siguraduhing installed ang Mitsubishi D80 driver.
• Sa iPad app: buksan habang online → Setup → Check for updates.

2. SA LAPTOP (sa mismong event, offline):
• Isaksak ang Mitsubishi D80 via USB. Buksan ang Windows Mobile Hotspot (o router).
• Kung Print Helper: i-double click ang "Open Laptop Print Station.bat" (i-Allow sa Windows Firewall: Private + Public). Kung Laptop App (kapag enabled sa Admin): i-click ang ⋯ → Offline Print Station.
• Sa dashboard: pwede mo i-click ang Driver Preferences at Test 4x6 / Test 2x6 Cut para ma-test agad si D80, at makikita mo yung Laptop IP + 6-Digit PIN.

3. SA IPAD APP (+ Canon 550D DSLR):
• Ikonekta ang Wi-Fi ng iPad sa hotspot/router ng laptop (piliin Keep Trying Wi-Fi kung mag-warn na no internet).
• Isaksak ang Canon 550D via USB adapter sa iPad (M/Av mode, Auto Power Off: Disable) → piliin sa Setup → Camera.
• Punta sa Setup → Printer → piliin 4x6 o 2x6 strips → i-ON ang "Laptop Print Station (Wi-Fi)" → tap "Find Laptop on Wi-Fi" → ilagay ang 6-Digit PIN → Connect → piliin ang Mitsubishi printer sa Printer 1.
• Pwede na i-ON ang Auto-print — lalabas na agad sa D80 bawat shot kahit walang internet!
