3. Isolated Hang Tests (Tap One at a Time)

Run these in order to pinpoint whether the freeze is caused by GPU canvas RAM, Camera frames, JPEG Save/Download, or AirPrint.

A. Quick Safe Triage

Runs Device Probe → 1–8 MP Canvas Ladder → 4R JPEG Encode (no camera/print dialog). Safe 10-second check.

B. Canvas Memory Ladder (1 → 24 MP)

Tests single-canvas release AND simultaneous multi-canvas hold (4 shots + 4R composite + print page) to find the exact 3 GB iPad ceiling.

C. Camera Live + 5× Capture

Starts iPad camera preview and captures 5 back-to-back stills, timing frame decode and memory spikes.

D. Save / JPEG Encode / Download

Renders 1800×2700 & 2400×3600 4R composites, benchmarks toDataURL, toBlob, base64 size, and triggers a test Save.

E. AirPrint / Print Sheet Test

Builds a 4R JPEG page and opens iPad printing (native __PBPrint if in app, else window.print()), watching 15s after return.

F. Exact Customer Flow: Save → Print

Captures photo (or test pattern), renders 4R composite, saves JPEG, waits 300ms, then prints — logging every micro-step to the server.
