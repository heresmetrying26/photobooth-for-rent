Wi-Fi & Wi-Fi Direct Printer Test

Diagnoses wireless photo printers (including Epson L8050 over Wi-Fi and Wi-Fi Direct 192.168.223.1): checks ports 631 & 9100, dumps full IPP capabilities, runs a zero-paper Validate-Job matrix, and optionally prints a 1-sheet sharpness & borderless ruler target.

Offline cache: ready (keep this tab open when switching to printer Wi-Fi Direct) Helper: not checked

Before you start (Android / Laptop)

  1. Android tablet: open the photobooth4u app once so its background helper (127.0.0.1:17321) is active (look for the Photobooth Helper Active notification). You can also run this exact same test inside the app under Setup > Printer > Wi-Fi / Wi-Fi Direct Printer Test.
  2. Keep this tab open before switching Wi-Fi to the printer's Wi-Fi Direct network (e.g. DIRECT-xx-EPSON...), because Wi-Fi Direct has no internet.
  3. Router Wi-Fi: Epson L8050 uses 2.4 GHz Wi-Fi only. Make sure router Privacy Separator / AP Isolation is off.
  4. Load 4×6 in glossy photo paper before Step 3 (Steps 1 & 2 use zero paper).
